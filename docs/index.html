The idea

A spatially embedded, gradient-free neural operator learns through the physical intersection of 3D geometry and dual chemical/electrical kinetics. Every update is strictly local and streaming: derivatives are computed by integration by parts against a one-pole exponential window (an IIR spacetime weak form), which suppresses finite-difference noise amplification by ≈5,500× at the reference settings; a per-node recursive least-squares loop then identifies the local coupling law at the observation-noise floor. A slow nematic-consensus layer rotates each neuron's 3D structural vector toward the coupling-weighted mean of its neighbors — a deterministic contraction gated by a chemical field — so the network's shape self-organizes into a focused corridor. The angle channel multiplies the weight channel: the effective connection is κ_ij = weight × chemical × (v̂_i · v̂_j), and the emergent shape is a spatially coherent, readable readout of the mechanism. On a real 277-year sunspot record the streaming weak form identifies the delay-space law at 481× lower holdout error than finite-difference identification, flat under up to 50% added measurement noise. In a playable maze (Flowrunner), the composed material — weights × chemistry × shape — routes at exactly oracle-level steps from noisy observations alone, while each channel alone fails. No fabricated numbers: every figure comes from committed result files.

Approach

Each neuron carries three state variables — activation u_i, a slow chemical state c_i, and a 3D structural vector v_i. The weight channel is identified locally: the network maintains running, exponentially-decayed spacetime integrals (the IIR weak form) and a per-node recursive least-squares loop over a polynomial basis, so the identified law contracts to the true local physics. The angle channel is a deterministic nematic consensus: each vector rotates toward the coupling-weighted mean direction of its neighbors, gated by the chemical field so geometry grows only on the chemically-potentiated corridor. The two channels meet in the effective connection κ_ij = weight × chemical × (v̂_i · v̂_j).

Real data — the 277-year sunspot record

The identification layer, unmodified, runs on the SILSO monthly sunspot series — 3,331 real observations, 1749–2026 — delay-embedded as a ring of 24 lag nodes. The law is frozen after training and evaluated on an unseen 27-year window (1991–2023). Hyperparameters are tuned only on a validation window; nothing downstream is retrained.

The material at 10,000 nodes

The dense plant solver is O(N³) per step; a sparse warm-started conjugate-gradient solve (the relaxation a physical network performs, exact to 1e-9 and verified identical to the dense solve) makes the step O(E). From 484 to 10,000 nodes: identification improves with scale, the shape stays readable at every size (r = 0.60–0.65 vs 0.34–0.42 for the raw weights), the memory advantage grows (~240× → ~630×), and per-node cost is sublinear. The honest limitation: the corridor-routing contrast saturates at 10³–10&sup4; nodes.

Theory — what the loop guarantees

Four theorems with numerical verification (theory.json): the weak-form noise floor is λ²σ², independent of the sampling interval (finite differences amplify as 2σ²/Δt² — a 2.2e5× gap at dt = 1e-3); streaming RLS contracts under persistence of excitation with tracking error linear in the law-drift rate (238× reduction, halved in 5 samples); angulation is monotone ascent on the alignment functional (0.511 → 0.878); and — the closed loop — chemical-gated morphogenesis perturbs identification by only ~7% while the shape grows.

Run it yourself

Python 3.9+; only numpy, matplotlib, and (for the game clip) Pillow are required. Every paper number is produced by these scripts from the committed result files.

pip install -r requirements.txt
python run_experiments.py --task sweep     --seeds 15 --T 4000 --out results.json
python run_experiments.py --task ablation --seeds 8  --T 4000 --out ablation.json
python run_experiments.py --task scale    --seeds 5  --T 4000 --sizes 7x7,11x11,15x15 --out scaling.json
python scale_large.py --sizes 22x22,32x32,64x64,100x100 --seeds 3 --T 1500 --out scaling_large.json
python real_benchmark.py --dataset sunspot --out real_benchmark.json
python real_benchmark.py --dataset enso    --out real_benchmark_enso.json
python theory.py
python flowgame.py --episodes 4 --out game           # the maze game + animated clip
python make_figures.py
python test_biomaterial_net.py                       # 12 sanity tests
