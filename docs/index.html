Morphogenetic Bi-Modal Networks

Weights aren't enough. Every neuron carries a 3D angle channel that multiplies the weight channel: weights say how strongly, angles say where. The network learns a physical law from noisy local observations — no global loss, no backpropagation — and its shape self-organizes into a readable, mechanistic map of what it learned.

01Abstract

A spatially embedded, gradient-free neural operator learns through the physical intersection of 3D geometry and dual chemical/electrical kinetics. Every update is strictly local and streaming: derivatives are computed by integration by parts against a one-pole exponential window (an IIR spacetime weak form), which suppresses finite-difference noise amplification by ≈5,500× at the reference settings; a per-node recursive least-squares loop then identifies the local coupling law at the observation-noise floor. A slow nematic-consensus layer rotates each neuron's 3D structural vector toward the coupling-weighted mean of its neighbors — a deterministic contraction gated by a chemical field — so the network's shape self-organizes into a focused corridor. The angle channel multiplies the weight channel: the effective connection is κ_ij = weight × chemical × (v̂_i · v̂_j), and the emergent shape is a spatially coherent, readable readout of the mechanism. On a real 277-year sunspot record the streaming weak form identifies the delay-space law at 481× lower holdout error than finite-difference identification (1.9e-5 vs 9.1e-3), flat under up to 50% added measurement noise. In a playable maze (Flowrunner), the composed material — weights × chemistry × shape — routes at exactly oracle-level steps from noisy observations alone, while each channel alone fails. No fabricated numbers: every figure comes from committed result files.

TL;DR — A neural network with two compute channels: scalar weights (strength) and 3D angles (direction). It learns laws from noisy observations with no backprop, its shape grows into a readable map of the law, and it plays a maze it never saw — angles are the computation; the shape is the interpretable spectrum.

03Approach

Each neuron carries three state variables — activation u_i, a slow chemical state c_i, and a 3D structural vector v_i. The weight channel is identified locally: the network maintains running, exponentially-decayed spacetime integrals (the IIR weak form) and a per-node recursive least-squares loop over a polynomial basis, so the identified law contracts to the true local physics. The angle channel is a deterministic nematic consensus: each vector rotates toward the coupling-weighted mean direction of its neighbors, gated by the chemical field so geometry grows only on the chemically-potentiated corridor. 05Real data — the 277-year sunspot record

The identification layer, unmodified, runs on the SILSO monthly sunspot series — 3,331 real observations, 1749–2026 — delay-embedded as a ring of 24 lag nodes. The law is frozen after training and evaluated on an unseen 27-year window (1991–2023). Hyperparameters are tuned only on a validation window; nothing downstream is retrained.

06Run it yourself

Python 3.9+; only numpy, matplotlib, and (for the game clip) Pillow are required. Every paper number is produced by these scripts from the committed result files.

pip install -r requirements.txt
python run_experiments.py --task sweep     --seeds 15 --T 4000 --out results.json
python run_experiments.py --task ablation --seeds 8  --T 4000 --out ablation.json
python run_experiments.py --task scale    --seeds 5  --T 4000 --sizes 7x7,11x11,15x15 --out scaling.json
python real_benchmark.py --out real_benchmark.json   # real sunspot record (SILSO)
python flowgame.py --episodes 4 --out game             # the maze game + animated clip
python make_figures.py
python test_biomaterial_net.py                         # 10 sanity tests

See the repository for the full README, methods, baselines, and eight documented failure modes. LaTeX sources for both papers (nmi_paper.tex, ieee_paper.tex) are included and regenerate with pdflatex.
